
# Network Dashboard

A networking and troubleshooting website designed to
explore basic networking concepts, connection information,
and common network problems.

## About the Project

Network Dashboard is a personal IT portfolio project
focused on networking, troubleshooting, and web development.

The website includes three pages:

### 1. Home
- Network overview
- Connection information
- Network status examples
- Dashboard statistics

### 2. Diagnostics
- Interactive diagnostic demonstration
- Introduction to ping
- Introduction to traceroute
- DNS lookup and latency explanations

### 3. Troubleshooting
- Common network problems
- Possible causes
- Step-by-step troubleshooting suggestions

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## Features

- Three-page website
- Responsive design
- Animated panda logo
- Interactive diagnostic demonstration
- Expandable troubleshooting guide
- Shared navigation and styling

## Important Note

This project uses sample network data.
The diagnostic tests are simulated and do not
perform real network scans or measure actual
device connectivity.

## Purpose

The goal of this project is to strengthen my
understanding of networking, troubleshooting,
HTML, CSS, and JavaScript.

Created as part of my Information Technology portfolio.
