COMMON PROBLEMS

What is going wrong?

Select a problem to see possible causes and troubleshooting steps.

01 No Internet Connection +

Possible causes: Router problems, disconnected cables, incorrect network settings, or an internet service outage.

What to try:

  1. Check whether your Wi-Fi is turned on.
  2. Check your router and modem connections.
  3. Restart your router if appropriate.
  4. Check whether other devices can connect.
  5. Contact your internet provider if the issue continues.
02 Slow Internet Speed +

Possible causes: Network congestion, weak Wi-Fi signals, background downloads, or outdated equipment.

What to try:

  1. Move closer to your wireless router.
  2. Close applications using a lot of bandwidth.
  3. Restart your network equipment if appropriate.
  4. Run an internet speed test.
  5. Contact your provider if speeds remain unusually slow.
03 DNS Resolution Problems +

Possible causes: Incorrect DNS settings, DNS server problems, or cached information.

What to try:

  1. Check that your device has the correct DNS settings.
  2. Try accessing another website.
  3. Use the nslookup command to test DNS resolution.
  4. On Windows, try ipconfig /flushdns.
  5. Contact your network administrator if the issue continues.
04 IP Address Conflict +

Possible causes: Two devices using the same IP address or an incorrect manual network configuration.

What to try:

  1. Check the IP address assigned to the device.
  2. Restart the affected device.
  3. Check the DHCP server configuration.
  4. Ask your network administrator to investigate duplicate addresses.
05 Cannot Connect to a Website +

Possible causes: DNS issues, browser problems, firewall restrictions, or a website outage.

What to try:

  1. Check whether other websites are working.
  2. Verify the website address.
  3. Try another browser.
  4. Check DNS resolution.
  5. Check whether a firewall or network policy is blocking access.
